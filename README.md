# Wind866

A 股盘后自动化：定时抓行情 → 算观察池 / 出看板 → 推飞书。
所有时间都是北京时间，准点由 Cloudflare Worker 触发，GitHub cron 只作兜底。

## 在跑的项目

| 仓库 | 做什么 | 档期 |
| --- | --- | --- |
| [BIGApush](https://github.com/Wind866/BIGApush) | 早晚新闻、盘中观察池、收盘选股（15 种形态策略）、个股查询、档期对账 | 08:13 / 12:53 / 19:33 / 21:53 |
| [astock-screener](https://github.com/Wind866/astock-screener) | 股东增减持 / 定增 / 回购 / 分红事件筛选看板 | 20:33 |

| [etf-feishu-push](https://github.com/Wind866/etf-feishu-push) | 全市场 ETF 各指数主力净流入 → 近 10 日对照图 | 20:03 |

## 几条共同的工程约定

- **数据日期 ≠ 运行日期**：cron 实测会迟到 3~10 小时，甚至跨过午夜。所有任务都按
  「行情时间戳里的日期」记账，跨夜只会延迟推送，不会丢档或错行。
- **推送幂等**：只有飞书确实返回成功才写台账，同一档期重复触发会被秒级跳过。
- **降级要说出来**：数据源失效时卡片/日志会明确写出降级口径，不假装数据完整。
- **漏跑可见**：档期对账每天核对三个仓库的「应到 / 实到」，缺口直接判红。
